# Normarchy 1.0.0

Norm Macdonald is, at last, built into your operating system.

Normarchy adds a compact wordmark to the Omarchy bar. One click opens a native
video panel; **Another Norm** keeps the break going. Pick a duration, use the
keyboard controls, or leave the panel playing while you return to the desktop.

The plugin stores no media and requires no account, credentials, installer, or
elevated privileges. Playback uses the tools already available on the target
Omarchy installation.

## Install

```bash
omarchy plugin add https://github.com/ctl0v0/normarchy.git --enable
```

See the repository README for controls, requirements, removal, catalog policy,
and technical details.
